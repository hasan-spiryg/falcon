# موقع فالكون — ساعات رياضية سورية

موقع إلكتروني متكامل لعلامة **فالكون** للساعات الرياضية، مع **لوحة إدارة شاملة** لتعديل كل محتوى الموقع وإدارة المنتجات والصور والطلبات.

---

## آخر التحديثات (حسب طلبك)

1. **«مجموعة الصقور» → «مجموعة الساعات»** — عنوان قسم المنتجات.
2. **«صقر برو» → «فالكون برو»** — اسم الساعة الرئيسية (FALCON PRO) في البطاقة والبانر ومينا الساعة ونموذج الطلب.
3. **«طليعة السرب» → «اقتني ساعتك»** — العنوان الفرعي للبانر وزر الاقتناء.
4. **حذف كل ما يتعلق بالذكاء والبلوتوث** — الساعة ساعة رياضية كلاسيكية:
   - حُذفت ميزة «تطبيق فالكون» ومزامنة البلوتوث من قسم التقنية، واستُبدلت بميزة «منبه مواقيت مدمج» (مواقيت مبرمجة داخل الساعة بلا هاتف ولا إنترنت).
   - حُذف ذكر «التطبيق» من مزايا قسم مواقيت الصلاة.
   - حُذفت كلمة «ذكي» من كل نصوص الموقع والوصف التعريفي (Meta).
5. **المركز الرئيسي في إدلب** — الشارة، قصة البراند («من إدلب، إلى معصم كل عربي»)، العنوان في التذييل، معرف `IDLIB` بجانب الشعار وفي الشريط المتحرك، والمدينة الافتراضية لعرض المواقيت صارت **إدلب**. (مراكز الصيانة: إدلب وحلب ودمشق).
6. **لوحة إدارة شاملة** — انظر أدناه.

## أقسام الموقع (عام)

| القسم | الوصف |
| --- | --- |
| الواجهة الرئيسية | عنوان رئيسي، ساعة حية SVG تعرض الوقت الفعلي والصلاة القادمة، إحصاءات |
| الشريط المتحرك | كلمات الهوية |
| مجموعة الساعات | بطاقات المنتجات (تُقرأ من قاعدة البيانات) |
| بانر فالكون برو | عرض درامي بصورة كبيرة وزر «اقتني ساعتك» |
| مواقيت الصلاة | ويدجت تفاعلية: 14 مدينة سورية، عد تنازلي، تقويم هجري، مفاتيح تنبيه |
| التقنية | 6 مزايا تقنية (سافاير، 20 ATM، بطارية، إضاءة، منبه مدمج، فولاذ 316L) |
| قصتنا | قصة البراند من إدلب + شريط الثقة |
| اطلب ساعتك | نموذج طلب (اسم، هاتف، مدينة، موديل) يُخزن في قاعدة البيانات |
| التذييل | نشرة بريدية، روابط، معلومات التواصل |

## لوحة الإدارة الشاملة

الرابط: **`/admin`** — كلمة المرور الافتراضية: **`falcon-admin`**
(تُغيَّر من ملف `.env` عبر `ADMIN_PASSWORD`)

| الصفحة | ماذا تُدير |
| --- | --- |
| نظرة عامة | إحصاءات (الطلبات، الجديد، المنتجات، المشتركون) + أحدث الطلبات |
| المنتجات | إضافة/تعديل/حذف/إخفاء ساعة: الاسم، الاسم اللاتيني، السعر، الوصف، الشارة، **الصورة** (رفع مباشر أو من المكتبة أو رابط)، المواصفات مع اختيار الأيقونة |
| محتوى الموقع | تعديل **كل نصوص وصور** الموقع: الواجهة الرئيسية (العنوان، النص، الإحصاءات)، الشريط المتحرك، عنوان قسم المنتجات، بانر فالكون برو، قسم مواقيت الصلاة ومزاياه، قسم التقنية ومزاياه، قصتنا، شريط الثقة، معلومات التواصل (العنوان والهاتف والبريد والمدينة)، التذييل — كل قسم يُحفظ ويُعاين بشكل مستقل مع زر «إرجاع الافتراضي» |
| الطلبات | عرض الطلبات، بحث وفلترة بالحالة، تغيير الحالة (جديد/مؤكد/تم التوصيل/ملغي)، حذف |
| المشتركون | قائمة بريد النشرة مع نسخ الكل وحذف |
| مكتبة الصور | رفع صور بالسحب والإفلات (حتى 5MB)، معاينة، نسخ الرابط، حذف |

كل تعديل في اللوحة **يظهر فوراً في الموقع** لأن المحتوى يُقرأ من قاعدة البيانات مع كل زيارة.

## البنية التقنية

- **Next.js 16** (App Router) + TypeScript + Tailwind CSS 4 + shadcn/ui
- **Prisma + SQLite** — جداول: `products`, `settings`, `orders`, `newsletter_subs`
- **Prayer times** — حساب فلكي محلي (طريقة سوريا: الفجر 18°، العشاء 17°) بلا خدمات خارجية
- **المصادقة** — جلسة موقّعة HMAC في كوكي HttpOnly (7 أيام)
- الملفات المرفوعة تُخزن في `public/uploads/` وتُخدم من `/uploads/...`

## ملفات مهمة

```
src/lib/site-defaults.ts        ← كل النصوص الافتراضية (يُتجاوزها المحفوظ في قاعدة البيانات)
src/lib/content.ts              ← دمج الإعدادات + زرع المنتجات الافتراضية
src/lib/admin-auth.ts           ← مصادقة لوحة الإدارة
src/app/admin/                  ← صفحات اللوحة
src/app/api/admin/              ← واجهات اللوحة (منتجات، محتوى، طلبات، مشتركون، وسائط، دخول)
src/components/falcon/          ← مكونات الموقع العام
src/components/admin/           ← مكونات لوحة الإدارة
prisma/schema.prisma            ← مخطط قاعدة البيانات
```

## التشغيل

```bash
bun run dev        # خادم التطوير على المنفذ 3000
bun run build      # بناء الإنتاج
bun run start      # تشغيل نسخة الإنتاج
```
